# 보라카이 가족 가이드 — 원본 데이터

- `raw/osm.json` — 보라카이 해안선·도로·해변 (Overpass API, OSM 기준 2026-05-31)
- `raw/osmapi.xml` — 스테이션 1~3 상세 OSM 데이터 (OSM API, 2026-11-23 수집)
- `raw/pois.txt` — 위 데이터에서 추출한 이름 있는 장소 목록 (id|이름|종류|좌표|영업시간|도로)
- `research/*.json` — 웹 검색 기반 조사 결과 (출처·날짜 포함, 미검증 항목은 null)
